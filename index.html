SOLAR CAPACITY DRAFT

먼저 확인해 주세요

  • 카카오맵 API는 건물 외곽선을 자동으로 추출해 주는 기능을 제공하지 않습니다. 검색된 주소의 위성지도 위에서 건물 모서리를 사용자가 직접 클릭해서 표시해야 합니다.
  • 면적과 모듈 배치는 클릭한 좌표(위도/경도)를 기준으로 계산한 근사치입니다. 실제 시공 전에는 반드시 현장 실측이 필요합니다.
  • 지붕 경사각을 입력하지 않으면(기본값 0°) 위에서 내려다본 평면 면적 기준으로 계산되며, 실제 경사 지붕 면적/모듈 수보다 적게 나올 수 있습니다.
  • 모듈 규격은 정확한 데이터시트를 확인하지 못해 기본값(2465×1134mm, 645W)으로 넣어 두었습니다. 실제 사용 제품의 데이터시트 수치로 반드시 교체해 주세요.

1. 카카오맵 연동 설정

키는 이 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

2. 주소 검색 및 건물 표시

지도를 확대한 뒤 지붕 모서리를 순서대로 클릭하세요. 점 개수 제한 없음 — 건물이 사각형이 아니어도 여러 점을 찍어 실제 모양대로 면적을 산출할 수 있습니다. 건물이 여러 동이면 "건물 그리기 시작"을 반복해 각각 그리세요.

3. 건물 목록 및 지붕 설정

아직 그려진 건물이 없습니다.

4. 모듈 및 설치 간격 설정

장변 2465×단변 1134mm(645W)는 확인되지 않은 추정 기본값입니다. 실제 사용할 모듈의 데이터시트 규격으로 반드시 수정하세요. 간격·여백 값도 표준이 아닌 조정 가능한 기본값입니다.

계산 결과 (건물별)

5. 발전량 및 수익 예상

발전시간(3.6 / 3.8 / 4.0시간)은 비교용으로 입력한 가정값이며 실제 발전량은 지역·설치각도·음영 등에 따라 달라집니다. 단가 200원/kWh은 입력하신 1등급 장기계약 기준 값이며 언제든 수정할 수 있습니다.
