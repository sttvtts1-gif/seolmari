태양광 발전용량 계산기 (초안/MVP) 사용 방법

1. ZIP 내용을 HTTPS 웹사이트에 올립니다. 파일 구조를 그대로 유지합니다.
2. 휴대폰/PC 브라우저로 해당 주소를 엽니다.
3. "1. 카카오맵 연동 설정"에 카카오 JavaScript 키를 입력하고 저장합니다.
   - developers.kakao.com 에서 애플리케이션을 등록하면 무료로 발급받을 수 있습니다.
   - 키는 이 브라우저에만 저장되며 외부 서버로 전송되지 않습니다.
4. 주소(도로명 또는 지번)를 입력해 검색하면 카카오맵이 해당 위치로 이동합니다.
5. 지도를 확대한 뒤 "건물 그리기 시작"을 누르고 지붕 모서리를 순서대로 클릭합니다.
   점 개수 제한이 없으므로 건물이 사각형이 아니어도 실제 모양대로 여러 점을 찍어
   면적을 구할 수 있습니다. "건물 완성"을 누르면 등록됩니다.
6. 건물이 여러 동이면 4~5번을 반복해서 각각 그립니다. 건물 목록에서 계산에 포함할
   건물을 체크박스로 선택할 수 있습니다.
7. 각 건물마다 "용마루선 그리기"로 지붕 마루선 양 끝점을 클릭하고,
   지붕 형태(남북지붕/동서지붕)와 남북지붕일 경우 뒷단 분할 단수(2단/3단)를 선택합니다.
8. "4. 모듈 및 설치 간격 설정"에서 실제 사용할 모듈의 데이터시트 규격(가로/세로/용량)으로
   반드시 값을 수정합니다. 기본값은 확인되지 않은 추정치입니다.
9. "발전용량 계산하기"를 누르면 건물별 모듈 배치 도식, 모듈 수, 설치 용량(kW)과
   3.6 / 3.8 / 4.0 시간 기준 발전량·예상 수익(원/kWh 단가는 직접 수정 가능)이 표시됩니다.
10. 화면 하단 "원시 데이터"에서 계산에 사용된 좌표·면적·모듈 수 원본 값을 복사할 수 있습니다.

중요 — 반드시 알아두어야 할 한계
- 카카오맵 API는 건물 외곽선을 자동으로 인식/추출하지 않습니다. 지붕 모서리는
  사용자가 위성지도를 보고 직접 클릭해서 표시해야 합니다.
- 면적과 모듈 배치는 클릭한 좌표를 기준으로 한 근사 계산입니다. 실제 시공 전에는
  반드시 현장 실측과 구조 검토가 필요합니다.
- 지붕 경사각을 입력하지 않으면(기본값 0°) 지도에서 내려다본 평면 면적 기준으로
  계산되어 실제 경사 지붕 면적/모듈 수보다 적게 나올 수 있습니다.
- 모듈 규격 기본값(645W, 2465×1134mm)은 정확한 데이터시트로 확인되지 않은 추정값입니다.
  실제 제품 데이터시트 값으로 교체해서 사용하세요.
- 발전시간(3.6/3.8/4.0시간)과 단가(200원/kWh)는 비교를 위해 입력한 가정값이며,
  실제 값은 지역·설치 조건·계약 조건에 따라 달라집니다.
