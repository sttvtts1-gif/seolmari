전화 알림 앱 사용 방법

1. ZIP 내용을 HTTPS 웹사이트에 올립니다. 파일 구조를 그대로 유지합니다.
2. 안드로이드 휴대폰의 Chrome으로 해당 주소를 엽니다.
3. 화면의 "앱 설치" 버튼을 누릅니다. 버튼이 안 보이면 Chrome 메뉴에서 "앱 설치" 또는 "홈 화면에 추가"를 선택합니다.
4. 설치한 앱을 열고 알림 권한을 허용합니다.
5. "테스트 알람을 1분 뒤로 설정" 버튼을 누릅니다.
6. 첫 테스트 중에는 앱 화면을 켜 둡니다.

주의
- 일반 웹앱은 앱을 완전히 종료하면 휴대폰 운영체제의 절전 정책 때문에 정해진 시각의 알림이 보장되지 않습니다.
- 화면이 열려 있으면 1초 간격으로 알람 시간을 확인하며, 알림과 진동/짧은 소리를 시도합니다.
- 완전히 종료된 상태에서도 확실한 알람이 필요하면 서버 푸시 알림 또는 Android/iOS 네이티브 앱 기능을 추가해야 합니다.
