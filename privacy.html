통화기록 개인정보처리방침

최종 수정일: 2026년 8월 26일

「통화기록」(패키지명 com.grandsun.callvault, 이하 "앱")은 휴대폰에 이미 저장되어 있는 통화녹음 파일을 정리하고 검색할 수 있게 하는 앱입니다. 이 문서는 앱이 어떤 정보를 다루고, 그 정보가 어디에 머무는지를 설명합니다.

핵심 요약 — 앱이 읽는 통화녹음·문자·연락처·통화기록은 전부 이용자의 기기 안에서만 처리되고 저장됩니다. 개발자는 이 정보에 접근할 수 없으며, 외부로 수집·전송하지 않습니다. 단 하나의 예외는 아래 4항의 AI 교정 기능으로, 이용자가 본인의 API 키를 직접 입력해 켰을 때에만 동작합니다.

1. 앱이 접근하는 정보와 이유

권한 / 정보사용하는 이유
저장공간의 통화녹음 파일
(모든 파일 접근 또는 폴더 선택)		 휴대폰 기본 전화앱이 만들어 둔 녹음 파일을 찾아 목록으로 정리하기 위해 읽습니다. 파일을 수정하거나 삭제하지 않습니다.
연락처 녹음 파일에 남은 전화번호를 사람 이름으로 바꿔 보여주기 위해 조회합니다.
통화기록 녹음 파일의 상대방·수신/발신 여부·통화시간을 정확히 맞추기 위해 대조합니다.
문자(SMS/MMS) 같은 사람과 주고받은 통화 내용과 문자를 한 화면에서 함께 검색하기 위해 읽습니다.
알림 녹음 파일 정리·변환 진행 상황을 알리기 위해 사용합니다.

이 앱은 통화를 직접 녹음하지 않습니다. Android 10부터 서드파티 앱의 통화 음성 접근은 운영체제 차원에서 차단되어 있으며, 앱은 휴대폰이 스스로 저장해 둔 파일만 읽습니다.

2. 정보가 저장되는 곳

정리된 목록, 음성을 변환한 텍스트, 불러온 문자는 모두 기기 내부의 앱 전용 데이터베이스에만 저장됩니다. 개발자의 서버는 존재하지 않으며, 이용자의 정보가 개발자에게 전달되는 경로도 없습니다.

3. 음성 → 텍스트 변환

녹음 음성을 텍스트로 바꾸는 처리는 앱에 내장된 변환 엔진이 기기 안에서 오프라인으로 수행합니다. 이 과정에서 음성이 외부로 전송되지 않으며, 인터넷 연결 없이도 동작합니다.

4. AI 교정·요약 기능 (선택, 기본 꺼짐)

이용자가 설정 화면에서 본인의 Anthropic API 키를 직접 입력한 경우에만 이 기능이 켜집니다. 켜져 있으면 변환된 통화 텍스트의 일부가 문맥 교정과 요약을 위해 Anthropic의 서버로 전송됩니다.

  • 키를 입력하지 않으면 이 전송은 전혀 발생하지 않습니다.
  • 이용료는 이용자 본인의 API 계정에 청구되며, 개발자는 관여하지 않습니다.
  • 전송된 내용의 처리는 Anthropic의 개인정보처리방침을 따릅니다.
  • 설정에서 키를 지우면 즉시 중단됩니다.

5. 광고

앱은 Google AdMob 광고를 표시합니다. AdMob은 광고 제공을 위해 광고 ID와 기기·앱 사용에 관한 일반 정보를 수집할 수 있습니다. 앱이 다루는 통화 내용·문자·연락처는 광고 사업자에게 제공되지 않습니다.

광고 맞춤설정은 휴대폰의 설정 → 개인정보 보호 → 광고에서 초기화하거나 끌 수 있습니다. AdMob의 데이터 처리에 관한 안내는 Google 광고 정책에서 확인할 수 있습니다.

6. 제3자 제공

개발자는 이용자의 정보를 제3자에게 판매하거나 제공하지 않습니다. 4항의 AI 교정 기능과 5항의 광고를 제외하면 앱에서 외부로 나가는 데이터는 없습니다.

7. 보관 및 삭제

모든 데이터는 기기 안에만 있으므로, 앱을 삭제하면 앱이 만든 데이터도 함께 삭제됩니다. 원본 통화녹음 파일은 휴대폰의 원래 위치에 그대로 남습니다.

8. 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 의도적으로 수집하지 않습니다.
